# JARVIS AI Video Studio

An Android-friendly AI video editing studio with a web client and Python media-processing backend.

## Project status

Initial scaffold is being prepared. The existing desktop assistant, if any, will remain untouched; this repository is dedicated to the video editor.

## Planned architecture

- `backend/`: FastAPI API and FFmpeg-based media processing
- `frontend/`: responsive web interface suitable for mobile browsers
- `docs/`: setup and development notes

## Planned MVP

- Upload and preview video
- Trim and cut clips
- Add captions and subtitles
- Add audio/music tracks
- Export edited video

## Requirements

- Python 3.11+
- FFmpeg
- Node.js 20+
